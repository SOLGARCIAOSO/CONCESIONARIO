### Modulos del sistema

### Gestion de usuarios y roles
Permite el control de acceso para administradores, vendedores y empleados del concesionario.

### Clientes e inventario
Registro y gestiOn de clientes, administracion del inventario de vehiculos y actualizacion de disponibilidad.

### Ventas y cotizaciones
Creacion de cotizaciones, reservas y registro de ventas de vehiculos.

### Historial del vehiculo
Gestion de informacion tecnica, registro de mantenimientos y propietarios anteriores.

### Pagos y facturacion
Control de pagos, financiacion y generacion de facturas.
